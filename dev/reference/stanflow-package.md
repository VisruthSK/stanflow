# stanflow: A Mildly Opinionated Stan Bayesian Workflow

Streamlines access to the Stan ecosystem by attaching core workflow
packages, surfacing conflicts, and providing helpers to set up Stan
interfaces with sensible defaults. Facilitates the Bayesian Workflow as
described in Gelman et al. (2020) <https://arxiv.org/abs/2011.01808>.
